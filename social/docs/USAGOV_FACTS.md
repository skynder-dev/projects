# CODEX_04: отдельные факты USA.gov

USA.gov разбирается отдельно от StudentAid: разделы h2/h3 (также h4–h6), пункты
списков вариантов и строки таблиц становятся отдельными утверждениями. Заголовки
внутри старой разметки абзацев и таблиц не склеивают страницу. Общий факт `identity`
содержит заголовок h1 и весь вводный текст. Раздел без абзацев сохраняет сам
заголовок: условие может быть написано только в нём. Вложенный список остаётся
целиком внутри родительского пункта, чтобы не отделять его ограничения.

`quote` — полный извлечённый `text_content`: HTML-сущности декодируются, между
блочными элементами ставится LF, внешние пробелы удаляются. Предложения не
редактируются, не сокращаются и не переводятся. В строке таблицы целые ячейки
соединяются LF. Это цитата извлечённого текста, а исходные HTML-байты отдельно
сохранены без изменений с SHA-256. `statement` повторяет цитату; общий факт
сохраняет прежнюю метку `USA.gov page:` перед заголовком и вводным текстом.

Ключ зависит от типа, пути заголовков и названия варианта/первой ячейки, а не от
номера строки. Для одинаковых названий добавляется порядковый суффикс. Вставка
другой строки или варианта не меняет прежние ключи; изменение названия меняет ключ.
`locator` хранит пути HTML-элементов и заголовков; для таблицы — путь и номер
строки (с учётом строки заголовков), подпись, номера, пути, текст и заголовки
столбцов. Каждая цитата связана с SHA-256 снимка и своим `excerpt_sha256`.

Навигация, breadcrumbs, feedback, Call/Chat USAGov и footer исключаются.
Скрытые условия внутри основного текста сохраняются. StudentAid, включая отказ
при JavaScript-оболочке, не изменён. Живые форматы в этом задании не проверялись.

`wages` удалён; имя и старый URL дают понятный отказ до чтения источника.
Регрессия условий recovered wages проверяется на `wage_laws` прежним синтетическим
файлом `usagov_wages_synthetic.html`. В существующем словаре ядра `wage_laws`
сохраняет намерение `wages`, налоговые возвраты — `unclaimed`; для `workers_comp`
новое неподдерживаемое намерение не придумывается.

## Завершённые программы и отбор

Явные выражения `has/have ended`, `is/are no longer available/accepting applications`
и `claim/application period ended` дают `expired: true`. Признак наследуется от
раздела к его вариантам и подразделам; если завершение указано в общем факте,
исключается вся страница. Дата окончания не угадывается. `expired: false` означает
лишь отсутствие распознанного сообщения о завершении, а не подтверждение доступности.

`record.json` и `claims.json` сохраняют весь разобранный материал, включая архивные
факты. `concept_record.json` и `concept_claims.json` содержат отдельный набор для
ядра. `claim_selection.json` фиксирует правило, лимиты, `selected_keys`,
`dropped_keys`, `expired_keys` и причины каждого пропуска. В `topics.json`
сохраняется такой же отчёт; рейтинг использует выбранные разделы. Страница без
содержательных незавершённых фактов исключается из текущих тем. Вводный текст и
пустой заголовок сами по себе не спасают страницу с одними завершёнными программами.

Правило отбора детерминированное:

1. Исключить завершённые факты и их зависимые факты.
2. Обязательно оставить общий факт и целые разделы с явными условиями,
   ограничениями или исключениями. Простой английский поиск условий намеренно
   консервативен; это не юридический анализ.
3. Затем выбирать строки таблиц, разделы обращения/поиска, пункты списков,
   остальные разделы. Внутри приоритета сохранять порядок страницы.
4. Вместе с каждым фактом оставить полные прозаические разделы его заголовка и
   предков. Не брать факт, если весь комплект зависимостей не помещается.

По умолчанию максимум 16 утверждений; `usagov_facts.max_claims` в `--config` может
задать другое положительное целое число. Остальные пределы не повышаются: контекст
описания — 16384 байта UTF-8 (владелец поднял предел перед CODEX_05);
предварительный бюджет сериализованных prompt + schema для прежнего отбора страницы —
18000 байт, с запасом для системного текста и оболочки существующего ядра. Слишком
длинные обязательные условия дают отказ и код 2, без готового запроса. Необязательный
факт пропускается целиком. В наборе для ядра сохраняются точные цитаты и их источники;
описание явно обозначено как проекция выбранных целых фактов, а не вся страница.

`--prepare-request` по-прежнему вызывает настоящий `concept_core.build_request` и
неизменённый допуск с проверкой токенизатора, политик и бюджета. Предварительный
отбор не означает успешный допуск. Старый запрос и старые входные данные удаляются
при отказе нового отбора. Модель не вызывается.

CODEX_05 добавляет отдельные программы для переполненной страницы energy. Условия
программы и все общие факты сохраняются целиком; подробности и отдельный расчёт
предварительного бюджета программы — в [ENERGY_PROGRAMS.md](ENERGY_PROGRAMS.md).

## Офлайн-проверки

Из `social/` (Python 3.11, новые проверки без сторонних библиотек):

```sh
python -B -m unittest tests.test_usagov tests.test_studentaid tests.test_usagov_facts -v
python -B -m socialreel source --source usagov --page unclaimed --fixture fixtures/usagov_table_synthetic.html --out runs/usagov-facts-table
python -B -m socialreel source --source usagov --page wage_laws --fixture fixtures/usagov_wages_synthetic.html --out runs/usagov-facts-wages
```

Из корня, затем из `social/`:

```sh
python -B social/.ci/run_social_concept_core.py
cd social
python -B -m unittest discover -s tests -t .
```

Прошли 88 тестов ядра и все 190 тестов полного набора. Отдельно добавлено 18 тестов
USA.gov; вместе с прежними проверками источников — 48. Полный набор использует уже
предусмотренные Pillow, pypdf, ffmpeg/ffprobe. Новые тесты блокируют сеть и проверяют
разделы, списки, таблицы, стабильность ключей, цитаты, SHA-256, локаторы, фильтрацию
шума, завершённые программы, отказ и запись пропущенных ключей. Настоящий построитель
запроса проверяется до границы допуска; успешный токенизатор и запуск модели не
имитируются. Живые сайты, актуальность программ и качество концепций не проверялись.
