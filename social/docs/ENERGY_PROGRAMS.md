# CODEX_05: несколько программ на одной странице USA.gov

Страница energy может содержать LIHEAP, WAP и помощь при отключённых коммунальных
услугах. Если она не помещается целиком, `source` выбирает первую программу в
порядке источника, которая помещается со **всеми** её незавершёнными фактами,
пунктами списков, исключениями и общими заметками страницы. Тексты не сокращаются,
не переводятся и не переписываются. Снимок, цитата, локатор и SHA-256 каждого
выбранного факта сохраняются. Завершённые программы не становятся текущей помощью.

## Запуск

Из `social/`, Python 3.11, полностью офлайн:

```sh
python -B -m socialreel source --source usagov --page energy --fixture fixtures/usagov_energy_programs_synthetic.html --out runs/energy-auto
python -B -m socialreel source --source usagov --page energy --program liheap --fixture fixtures/usagov_energy_programs_synthetic.html --out runs/energy-liheap
python -B -m socialreel source --source usagov --page energy --program 2 --fixture fixtures/usagov_energy_programs_synthetic.html --out runs/energy-wap
python -B -m socialreel topics --sources usagov --fixture fixtures/usagov_energy_programs_manifest_synthetic.json --as-of 2026-11-04 --out runs/energy-topics
python -B -m socialreel source --topics runs/energy-topics/topics.json --topic-id usagov:energy:wap --out runs/energy-wap-replayed
```

Fixture явно синтетический и намеренно подробный, чтобы воспроизводить отказ всей
страницы при успешном отборе отдельной программы. Это не действующие правила помощи.

Для живого источника уберите `--fixture`:

```sh
python -m socialreel source --source usagov --page energy --program wap --out runs/energy-wap-live
```

Эта живая команда в задании не проверялась. `--program` принимает имя без учёта
регистра, полный заголовок программы или номер **от 1** в порядке источника.
Известные имена energy: `liheap`, `wap`, `disconnected`. Ошибка в имени показывает
доступные варианты; явно выбранная слишком большая программа получает отказ,
без автоматической подмены другой программой. Для StudentAid/Scorecard этот
параметр не поддерживается. На странице без нескольких распознанных программ
нужно опустить параметр.

Без параметра сначала проверяется вся страница с несколькими программами. Если
она помещается, сохраняется целиком. Иначе пробуются полные программы по порядку.
CLI прямо сообщает `automatic_first_fitting` и выбранное имя. Для unclaimed и
налоговых возвратов прежние fixtures и поведение отбора не изменены.

## Границы программ и общие условия

Выбор опирается на исходные заголовки и их вложенность. Распознаются LIHEAP, WAP,
полные названия этих программ, заголовки про отключение utilities и форма
`Find out if you are eligible for NAME and apply`. В последнем случае имя — slug
указанного NAME. Если общий заголовок сам не называет программу, но его прозаический
раздел явно называет ровно одну известную программу, этот заголовок и его потомки
относятся к ней. Повторные разделы той же программы объединяются.

Группировка включается, когда распознаны минимум две программы. У подразделов
владельцем становится ближайший распознанный заголовок. Зависимости прозаических
условий определяются по путям HTML-элементов, поэтому одинаковое слово `Eligibility`
в разных программах не склеивает их условия. Все факты выбранной программы
обязательны, включая пункты списков. Они не выбрасываются ради успешного отбора.

Всё, что нельзя однозначно отнести к программе, сохраняется как общий материал и
прилагается к каждой программе целиком. Так остаётся и заметка `Rules differ by
state`, и общее ограничение без известных ключевых слов. Неоднозначный большой
общий раздел может привести к отказу; его смысл не угадывается ради обхода лимита.

`record.json` и `claims.json` по-прежнему содержат полный архив страницы.
`concept_record.json` и `concept_claims.json` содержат выбранный набор.
`claim_selection.json` дополнительно записывает:

- `chosen_program`, `program_selection` и пояснение автоматического выбора;
- каталог `programs` с именами, номерами, заголовками, локаторами и ключами;
- `left_out_programs` с причинами: другой явный выбор, первая помещающаяся
  программа, слишком большой полный набор либо отсутствие текущих фактов;
- `page_wide_condition_keys`, `whole_page_state`, выбранные и пропущенные ключи.

## Темы и допуск

`topics --sources usagov` выдаёт по теме на распознанную программу, например
`usagov:energy:liheap`, `usagov:energy:wap`, `usagov:energy:disconnected`.
Страница читается один раз; темы используют один снимок и полный архив с отчётом
своего отбора. Непомещающаяся или завершённая программа попадает в `excluded`.
История просмотра применяется к полному ID программы независимо от соседних.
Воспроизведение темы проверяет SHA-256, заново читает HTML и определяет программу
по ID и проверенным заголовкам. Редактирование поля `program`, цитат или отчёта
в topics.json не подменяет факты; `--program` другой программы для такой темы даёт отказ.

Предел контекста **16384 байта UTF-8**, установленный владельцем до задания,
сохранён. Ядро, допуск, JSON-контракт и их тесты не изменялись. Старый отбор
одиночной страницы сохраняет предварительные 18000 байт prompt + schema. Для
полной программы этот предварительный бюджет рассчитывается от действующего
лимита допуска: 40960 − 14000 = **26960 байт**, с резервом для системного текста
и оболочки. Это устраняет ложный отказ полного набора программы, который помещается
в действующий запрос. Максимум утверждений по умолчанию остаётся 16.

`--prepare-request` по-прежнему вызывает настоящий `concept_core.build_request`:
полный запрос, токенизатор и все ограничения проверяются неизменённым допуском.
Успех предварительного отбора не объявляется успешным допуском. Если ни одна
полная программа не помещается, сохраняется отказ и код 2. Старые готовые данные
ядра удаляются перед новой попыткой, чтобы ошибка выбора не оставила готовый
комплект от предыдущей программы. Модель не вызывается.

## Проверки

Из корня репозитория:

```sh
python -B social/.ci/run_social_concept_core.py
```

Из `social/`:

```sh
python -B -m unittest discover -s tests -t .
python -B -m unittest tests.test_usagov tests.test_usagov_facts tests.test_studentaid tests.test_usagov_programs -v
```

Офлайн проходят 88 тестов ядра и все 210 тестов полного набора. Добавлено 20
проверок программ; вместе с прежними проверками источников — 68. Новые проверки
используют стандартную библиотеку Python 3.11 и блокируют сеть. Проверяются оба
контракта реального построителя запроса до границы допуска, точные цитаты, локаторы,
SHA-256, полный набор условий, выбор по имени/номеру, автоматический пропуск,
завершённые программы, темы, история и воспроизведение снимка. Успешный допуск и
запуск модели не имитируются. Живой формат сайта, актуальность правил и качество
концепций в этом задании не проверялись.
