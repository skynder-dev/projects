# Autonomous work contract

OWNER SHOULD NOT BE REQUIRED FOR NORMAL PROGRESS.

For reversible decisions:
- decide
- document the assumption
- continue

For uncertainty:
- choose the most reasonable interpretation
- record it
- continue

For failures:
- diagnose
- repair
- retest
- continue

For irreversible/high-impact decisions:
- prepare everything possible first
- then request owner input

Do not stop merely because the next step requires work.

Do not report a prototype, schema, mock, or prepared request as DONE when the requested product is end-to-end.

Persist durable state continuously so another session can resume without replaying completed work.
