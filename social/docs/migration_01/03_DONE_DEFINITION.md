# DONE definition

Social migration pilot is DONE only when all of the following are true:

1. At least one current real topic is selected.
2. Research is based on real accessible sources.
3. Every factual claim used in the Reel has source lineage.
4. One complete Reel package exists as real files, not placeholders.
5. Package contains script, timing, voice plan, visual plan/assets or exact visual-generation inputs, metadata and hashes.
6. Package is accepted by the MediaEngine handoff adapter or an equivalent local adapter.
7. A playable final Reel is produced.
8. Final Reel is inspected for basic technical validity.
9. Source -> package -> final video identities are recorded.
10. A second run or deterministic verification shows the workflow is repeatable enough to continue.
11. No claim of success is based only on database rows, string checks, static HTML, mocked providers or package schema validation.

Target counters after the first pilot:
- REAL REEL PACKAGES >= 1/3
- FINISHED MEDIAENGINE REEL >= 1/1

Do not stop at 3/3 scripts with 0 finished videos.
