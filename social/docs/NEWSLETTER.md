# Черновики рассылки и памятки

Из папки `social`:

```powershell
python -m socialreel newsletter draft --store results/concept-store --bundles results/source-one results/source-two --out results/newsletter --as-of 2026-11-08
python -m socialreel newsletter checklist --bundles results/unclaimed --out results/checklist
```

Принимаются отдельные папки `source` bundles с `record.json`, `claims.json`
и исходными снимками. USA.gov HTML и Grants.gov JSON/нормализованные экспорты
перечитываются с проверкой SHA-256. Редактируемые цитаты в claims.json не считаются
источником истины: факты восстанавливаются из снимков. Нет сети, модели или отправки.

Рассылка: `newsletter.md`, `newsletter.txt`. Памятка: `checklist.md`, печатный
`checklist.html`. Рядом `trace.json` связывает заголовок, каждую цитату и условия
с ключом факта и источником. `summary_ru.json` объясняет выбор и исключения.
`sponsor-slot.txt` содержит выключенное место для решения владельца; в выпуск
оно не вставляется. Адрес отправителя и ссылка отписки остаются заглушками.

Решения читаются через существующий проверяющий код ConceptStore: только текущий
явный выбор, совпадающий URL и точная формулировка опорного факта повышают тему.
Текст идеи владельца не становится фактом. Затем идут снимки с более поздним
временем наблюдения, при равенстве — порядок входных папок. Отсутствующий store
не создаётся; повреждённый существующий store даёт явную ошибку.

До пяти тем; если нет трёх пригодных, выдаётся меньше с отметкой в отчёте.
Основной текст — 2–3 предложения из целых цитат, без переписывания или обрезки
условий. Неподходящие длинные цитаты пропускаются. Условия сохраняются отдельно
целиком. Истёкшие факты, прошлые даты и зависимые строки исключаются; при прошлом
условии пропускается весь bundle. Это намеренно консервативно: исторические даты
могут исключить полезный материал. Живая актуальность не подтверждается.

Памятка берёт только строки таблиц или явно помеченные места из источников
о невостребованных деньгах/зарплате. Обычные списки навигации местами не считаются.
Для компактной страницы лимит — пять строк и 2200 символов цитат с условиями;
лишние целые строки перечисляются в отчёте. Итоговое число печатных страниц зависит
от браузера и настроек принтера. HTML экранируется; внешних шрифтов и ресурсов нет.

Проверки: `python -m unittest tests.test_newsletter -v`,
полный набор: `python -m unittest discover -s tests -t .`.
