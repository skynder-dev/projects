# SBA: источник для бизнес-канала

Из папки `social`:

```powershell
python -m socialreel source --source sba --page loans --out results/sba
python -m socialreel source --source sba --page local_assistance --program sbdc --out results/sbdc
python -m socialreel topics --sources sba,grants --out results/business-topics
```

Каталог: `loans`, `7a`, `microloans`, `sbir_sttr`, `grants`,
`local_assistance`, `disaster`, `contracting`. Все восемь URL и форматы страниц
**не проверены вживую** (URL not checked live). SBIR/STTR направлен на
предполагаемую страницу SBA об America's Seed Fund, без перехода на сторонние сайты.

Цитаты не сокращаются: остаются разделы, списки, строки таблиц, координаты
в HTML и SHA-256 снимка/цитат. При выборе программы сохраняются все общие факты
страницы, включая условия. Узнаются только явно названные программы в заголовках;
неоднозначный текст остаётся общим. Истёкшие факты помечаются и исключаются;
если полный комплект условий не помещается, выдаётся отказ.

В общем поиске с `sba` страницы SBA получают приоритет. Для Grants.gov в бизнесной
рубрике код 23 должен быть подтверждён, без неизвестных категорий и кода 99,
и составлять хотя бы половину перечисленных категорий (не более двух категорий
всего). Это консервативное редакционное правило, а не вывод о праве на помощь.
Старый отдельный поиск Grants.gov сохраняет прежние правила для НКО, чтобы не
менять его контракт. Новое ограничение можно также включить в конфигурации:
`topics.small_business_channel: true`.

Никакие суммы, сроки или право конкретного бизнеса на помощь не выводятся
из наличия страницы. Подготовка источника не вызывает модель и не публикует ролик.
Проверки используют только синтетический HTML, без сети.
