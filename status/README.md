# Состояние чатов проектов (для окна на ПК владельца)

Каждый чат проекта (Forge, MedEng, Social, RevEng) сам пишет свой файл `status/<Проект>.json`:
`{"project": "Forge", "state": "working|waiting|idle", "what": "коротко, по-русски", "at": "UTC ISO"}`
- в начале работы: `working` + что делает;
- в конце: `waiting` + что нужно от владельца, или `idle`;
- без лишнего: один маленький коммит в начале и в конце, не на каждом шаге.
Окно на ПК читает эти файлы раз в минуту. `working` старше 30 минут без обновления окно показывает как «нет вестей».
