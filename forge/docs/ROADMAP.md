# Merch Forge — план на 10 часов (с 2026-10-10 02:15 CT)

Цель: чтобы ты мог пройти путь «идея → макет → проверки → пакет для Amazon → продажи» сам, без моих пояснений и без ошибок.
Правило для каждого блока: изменения сразу в main → проверка на настоящем Windows (GitHub) зелёная → обновлены CURRENT_STATE / WORKLOG.
Без твоего разрешения не делаю: изменения сервера (Supabase), платную генерацию, публикацию.

На «Главной» — число таких пунктов. Проверено на Windows с тестовыми продажами.
- ✅ **Блок 3 — 063.** Клик по идее в «Конвейере» открывает вкладку, где продолжать: ОСТАВИТЬ без макета → «Макеты», макет принят → «Проверки», проверки/пакет/опубликовано → «Публикация». В каждой строке написано, что откроется. Проверено на Windows для трёх этапов.
- ✅ **Блок 4 — 064.** В «Проверках» кнопка «Подтвердить проверки…»: форма с понятным чек-листом (IP, правила Amazon, текст карточки), для каждой — «всё в порядке / проверить ещё / проблема». «Всё в порядке» требует ссылку и галочку «я сам(а) проверил(а)». Рядом с JSON-шаблоном лежит CHECKLIST.txt на языке интерфейса. Ошибки импорта говорят, что делать. Проверено на Windows: форма, русская ошибка без галочки, сохранение, все проверки зелёные.
- ✅ **Блок 5 — 065.** В «Проверках» карточка «Amazon-профиль печати»: размер, DPI, площадка, тип товара и сколько дней осталось; предупреждение за 7 дней, «истёк», «нет профиля». Кнопка «Заполнить Amazon-профиль…» — форма: выбираете скачанный шаблон Amazon, размер и отпечаток файла заполняются сами, ставите галочку. Проверяет тот же импортёр, что и раньше. Проверено на Windows: импорт через форму, статус, проверка печати зелёная.
