WHAT IS NEW (077) - fixes from the fourth independent review
- The automatic copy and "Restore from a copy" can no longer get in each other's way: the copy holds a lock,
  a restore waits up to 20 seconds for it (then says so), and a second copy never starts at the same time.
- If automatic copies stop working, Home -> My data says so (with the reason) even when older copies exist.
- A failed copy no longer leaves a half-written ZIP; a file that disappears while copying is skipped.
- Automatic copies kept: 3 (they can be large).
- Includes 076 and earlier (055-075).
