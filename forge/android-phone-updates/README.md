# Forge для телефона: канал обновлений

Приложение `dev.forge.app` (свайп-колода Forge) берёт отсюда `update.json` и ставит новую версию, только если совпали
SHA-256, имя пакета, номер версии и ключ подписи с уже установленным приложением. Подписывает сборка в приватном
репозитории владельца; в этой папке только готовые APK. Старый канал Forge Mobile (`dev.forge.mobile`) — в
`forge/android-mobile-updates/`, его не трогаем.
