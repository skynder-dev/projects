# Product spec

## Mission

Social finds a current factual topic, researches it from trustworthy sources, converts the research into a concise high-quality vertical Reel package, and produces a finished playable Reel.

## Required end-to-end flow

1. Select or refresh one real current topic.
2. Gather source-grounded facts.
3. Build a factual claim ledger.
4. Write a short Reel script with hook, body and close.
5. Produce voice instructions/audio-ready text.
6. Produce visual plan/assets or exact visual prompts.
7. Create one deterministic Reel package with exact hashes.
8. Hand package to MediaEngine.
9. Produce and verify a playable final video.
10. Preserve evidence and exact input/output identities.

## Non-goals

- Another text editor.
- Another backend-only milestone.
- Another UI redesign.
- Fake/demo success.
- Placeholder packages.
- A research report with no finished Reel.
- Infrastructure work that does not move the end-to-end counter.

## Content vertical

The proven live vertical is U.S. grants / Grants.gov. Claude may retain it for the pilot because it already has a proven source path, but the architecture must remain capable of supporting other factual verticals later.
