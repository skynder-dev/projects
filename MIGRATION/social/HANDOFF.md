## 1. Что это

**Social** — программа, которая берёт **настоящую актуальную федеральную возможность финансирования** (Grants.gov) и превращает её в **готовый вертикальный Reel** (MP4 1080×1920) с проверкой фактов, без Supabase и без ручных шагов.

Конвейер: Grants.gov API (живой, без ключа) → выбор темы (оценка, без повторов) → реестр утверждений (только официальные поля) → сценарий (шаблон или Claude, с валидацией) → озвучка (Piper TTS, бесплатно) → кадры (Pillow) → MP4 (ffmpeg) → проверка (ffprobe, полное декодирование, громкость, распознавание речи) → пакет с SHA-256 (цепочка от источника до видео).

## 2. Текущее состояние

- Работает на **GitHub Actions** (workflow `social-reel`; запуск вручную «Run workflow»: сколько Reels, необязательный id возможности; ~2–3 минуты на Reel). Результаты: ветка `social-results` (индекс `README.md`, `latest/`, `runs/<id>/` с видео, обзором и манифестами), плюс артефакты запуска.

## 5. Почему фактам можно доверять (устройство проверки)

- Утверждения копируются из **официальных полей Grants.gov** (`claims.py`); у каждого записан файл снимка, его SHA-256 и поле JSON.
- Писатели (шаблон или LLM) могут только **ссылаться** на утверждения. Валидатор отвергает сумму, дату или число, которых нет в процитированном утверждении, рекламные фразы («free money», «you qualify»), неопределённые количества и отсутствие финальной фразы «проверьте официальное объявление». Некорректный сценарий LLM заменяется шаблоном; нерассмотренное не рендерится.
- Время считается **по синтезированному звуку**, не угадывается.
- Итоговый MP4 проверяется (`verify.py`): ffprobe, полное декодирование, громкость; `rebuild` должен дать побайтово тот же файл.
- Запуски на фикстурах и голос `silent_test` никогда не принимаются.

## 6. Где что лежит (`social/…`)

| Что | Путь |
| --- | --- |
| Программа | `socialreel/` (`grants.py`, `claims.py`, `writer.py`, `voice.py`, `render.py`, `verify.py`, `pipeline.py`, `common.py`); запуск `python -m socialreel run`, самопроверка `python -m socialreel selftest` |
| Конфигурация | `config.json` (ключевые слова поиска, выбор, писатель, голос; `llm.allow_spend=false`) |
| Тесты, фикстуры, шрифты | `tests/`, `fixtures/` (настоящие записи, выгруженные из прежнего, выведенного из использования коннектора Supabase; только для офлайн-тестов), `assets/fonts/` (Inter, OFL) |
| Документы | `docs/CURRENT_STATE.md`, `NEXT_ACTION.md`, `OWNER_REVIEW.md`, `WORKLOG.md`, `docs/migration_01/` (пакет прошлой миграции: спецификация, правила, ловушки, граница MediaEngine) |
| Результаты | ветка `social-results`; ветка `social/v1` влита в `main` |

Локально: Linux или Windows, Python 3.11, ffmpeg; `pip install -r requirements.txt`, затем `python -m socialreel run`.

## 9. Мои наблюдения (по документам, не по запуску)

1. **Репозиторий публичный, значит видео в `social-results` и артефакты запусков скачивает кто угодно.** До ответа на пункт 4 решений держите это в уме; для новых тем решите, нужен ли приватный репозиторий.
2. **Переход в ChatGPT ломает только один компонент: писатель на Claude.** Он ходит в Anthropic через секрет `ANTHROPIC_API_KEY`. Остальной конвейер (Grants.gov, Piper, Pillow, ffmpeg, проверки) от поставщика ИИ не зависит. Варианты: оставить шаблонного писателя (бесплатно, уже принято 5 Reels) или написать адаптер под OpenAI с той же проверкой валидатором, но только после «да» на расход.
3. **Главная находка пилота — ошибка с «агентством = контакт».** Она поймана только живым прогоном и ручным обзором. Автоматическое принятие Reel без обзора человеком опасно: сохраните шаг «обзор и отзыв» (`RETRACTED.md`) и не включайте публикацию в соцсети без него.
4. **Числа в `CURRENT_STATE.md` расходятся с `OWNER_REVIEW.md`.** Приведите их в порядок первым делом, чтобы новый ассистент не начал с неверного состояния.
5. **Не расширяйте Social в сторону бэкенда или интерфейса:** прошлые попытки (V7, UI-версии) отмечены как ловушки; продукт — готовый Reel с фактами, а не инфраструктура.
