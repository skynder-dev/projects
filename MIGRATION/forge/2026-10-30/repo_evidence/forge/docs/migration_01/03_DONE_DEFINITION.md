# DONE DEFINITION

A migration work session is not DONE merely because code was edited or a UI screen renders.

## Required before calling the next Forge candidate DONE
1. Exact 054 source is extracted and audited.
2. Existing owner review path is regression-tested. KEEP/EDIT/REGEN/SKIP enablement and persistence must be verified to the strongest environment available; any missing Windows-native proof must be explicitly labeled.
3. Discover/Research can create a **real local concept draft** bound to source/research provenance. The draft must appear in the normal concept workflow without database fakery or manual file surgery.
4. The created draft can proceed to owner review and no-dispatch artwork preparation.
5. No generation/Accept/Submit authority is silently broadened.
6. Static/integrity tests pass, and relevant runtime tests pass in the available environment.
7. A deterministic or at minimum hash-manifested release ZIP is produced.
8. `CURRENT_STATE.md`, `WORKLOG.md`, and `NEXT_ACTION.md` describe exactly what is proven and what remains.

## Product-level long-term DONE
Forge eventually needs a trustworthy end-to-end path from research to production-ready merch packages, with owner interaction limited to subjective creative approval and explicitly authorized external actions.
