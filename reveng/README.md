# RevEng engine v0.1 — автономный сканер бизнес-возможностей (`reveng_v6_independent`)

Программа сама ведёт цикл: **поиск → проверка источников → hard-gates → единый скоринг → deep screen → решение → отчёт**.
Не зависит от вас лично: в глобальном скоринге нет ни одного поля о владельце (это проверяется тестом).
Нужен только **Node.js 20+** (на Windows: `reveng.cmd`). Зависимостей нет.

## Запуск (первый раз)
1. Скопируйте `config.example.json` в `config.json`. Для платного прогона:
   `budget.allow_spend: true`, укажите цены из прайса вашего провайдера (движок цены НЕ угадывает) и лимиты (`max_calls`, `max_usd`).
2. Ключ: переменная окружения `ANTHROPIC_API_KEY` (или `OPENAI_API_KEY` и `llm.provider: "openai"`).
3. `reveng doctor --config config.json` — проверка конфигурации и лимитов.
4. `reveng run --config config.json --dry-run` — увидеть промпты без единого вызова.
5. `reveng run --config config.json` — полный прогон. Результат в `runs/run_<время>/` (`REPORT.md` — то, что читать первым).
Прерванный прогон продолжается: `reveng run --config config.json --resume runs/run_...` (завершённые стадии не повторяются, вызовов не будет).

Другие команды: `reveng import --raw a.json,b.json` (кандидаты, исследованные вне движка; всегда PROVISIONAL, победитель невозможен),
`reveng measure --id X --file evidence.json` (Phase E: замер преимущества прототипа контрактом G280), `reveng selftest` (44 теста).

## Как устроено (почему можно доверять результату)
| Стадия | Что делает | Где защита |
|---|---|---|
| discover | LLM с веб-поиском предлагает ≥4 кандидата на семейство по схеме; плюс официальные API (HN Algolia, GitHub, Stack Exchange, npm, iTunes Search) | текст из сети изолируется контрактом G280 `untrusted_source_isolation` |
| research+verify | **страницы чужих сайтов не скачиваются.** Два вызова LLM: (1) поиск ВКЛ — заметки прозой, провайдер прикладывает цитаты; (2) поиск ВЫКЛ — JSON, где доказательства только ссылки `C#` (цитата провайдера = verified) / `S#` (URL из поиска = search_confirmed). Выдуманные ссылки отбрасываются | нет цитат ⇒ доказательство не засчитано; «URL видели, цитаты нет» весит 0.5 и не проходит gate без ≥2 подтверждённых |
| gates | лимиты «эталонного входящего игрока», измеримое преимущество против конкурента (бесплатный конкурент = преимущества нет), falsifier, глубина проверенных доказательств, детектор «языка владельца» | детерминированно |
| score | 13 измерений, веса прямо из G280 `scoring_profiles.js` (профиль balanced); 5 измерений считаются из чисел, 8 — оценка LLM, но оценка >3 без проверенной цитаты урезается до 3 | guard целостности пересчитывает всё и падает при любом расхождении raw/adjusted/ранга |
| deep | для лучших survivors: конкуренты, цены, ограничения, модель экономики через G280 `economics_contract` + пессимистичный сценарий | одинаковый чек-лист и минимум проверенных доказательств для всех |
| decide | winner / conditional_winner / no_winner | победитель невозможен при <30 кандидатов, <8 семействах, непроверенных доказательствах, нарушении целостности, лидер без deep screen |
| report | `REPORT.md`, `snapshot_<id>.json` (контракт G280 decision_snapshot: verified/unverified/unknown), `MANIFEST.json` с SHA-256, `checkpoint.json` | |

**Расходы:** по умолчанию любой платный вызов блокируется (`SpendNotAuthorized`). Ничего не публикуется, никому не пишется, аккаунты не меняются.

## Легальный режим
- Прямые запросы только к официальным API из списка (`src/fetcher.js`), с лимитами и User-Agent с контактом; любой другой хост блокируется до сетевого вызова (тест).
- Веб-поиск выполняет провайдер (Anthropic) по своим правилам; программа сайты конкурентов не открывает и не копирует.
- Неофициальные эндпоинты (например, поиск Steam) удалены. Перед коммерческим использованием стоит показать условия источников юристу.
- Сначала `reveng smoke` (1 вызов, ≤3 поисков), и только потом `reveng run`. Два неразобранных ответа подряд останавливают прогон.

## Что проверено и чего НЕ проверено (классы доказательств не смешаны)
- **Tests verified (44/44):** математика скоринга, guard целостности, gates, политика сети (чужие хосты не трогаются), разрешение доказательств по ссылкам C#/S# (двухфазный протокол), регрессия на сбой живого прогона, бюджет-стопор, разбор ответов Anthropic против локального mock, сквозной прогон с тестовым LLM, возобновление.
- **НЕ проверено вживую:** ни один вызов реального LLM-провайдера и ни одно реальное API источников (в среде сборки интернет закрыт, ключа нет). Формат запроса Anthropic/OpenAI и формы ответов HN/GitHub/Steam/и др. написаны по документации и проверены только на моках/фикстурах. Первый реальный прогон — это и есть live-проверка; возможны правки.
- **Не Windows-проверено** (собрано и протестировано на Linux, Node 22).
- Рынок/спрос не «валидирован»: движок собирает публичные свидетельства, а не результаты продаж.
